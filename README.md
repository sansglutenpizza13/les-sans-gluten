# Les Sans Gluten — Saison 1

Site officiel de la série illustrée indépendante « Les Sans Gluten ».

## Hébergement

Le site est hébergé exclusivement sur GitHub Pages.

Domaine officiel :
https://lessansgluten.fr

## Contenu

- `index.html` : page d’accueil
- `episode-1.html` : épisode 1
- `episode-2.html` : épisode 2
- `episode-3.html` : épisode 3
- `episode-4.html` : épisode 4
- `styles.css` : mise en page desktop et mobile
- `script.js` : interactions du site
- `CNAME` : domaine personnalisé lessansgluten.fr

## Publication

Toute modification validée est enregistrée sur la branche `main`.

GitHub Pages publie automatiquement la dernière version du site.
